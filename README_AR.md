# دوامي — مشروع Android

هذا مشروع Android Studio أولي لتطبيق «دوامي» يعمل دون اتصال بالإنترنت ويحفظ بياناته محلياً على الجهاز.

## إنشاء APK
1. فك ضغط الملف وافتح مجلد `DawamiAndroid` بواسطة Android Studio.
2. انتظر مزامنة Gradle وتنزيل Android Gradle Plugin وAndroid SDK إذا طُلب ذلك.
3. من القائمة اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. ستجد الملف الناتج عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## الموجود في النسخة الأولية
- لوحة رئيسية تعرض التاريخ ومؤشر المناوبة.
- جدول أسبوعي قابل للتنقل بين الأسابيع.
- إضافة مناوبة باسمها ووقت بدايتها ونهايتها ولونها.
- إدارة قائمة الموظفين محلياً.
- حفظ البيانات على الجهاز باستخدام التخزين المحلي.
- واجهة عربية RTL.

ملاحظة: هذه نسخة أولية محلية لجهاز واحد، وليست بعدُ نظام شركة متعدد المستخدمين أو متزامناً بين أجهزة الموظفين.
